# WAFFLE IT - Bold Website

A bold, innovative website for WAFFLE IT, a waffle business in Douala, Logbaba.

## Features

- **Cinematic Design**: Inspired by modern bold aesthetics with black backgrounds and orange accents
- **Bilingual Support**: French/English language toggle
- **Loading Screen**: Animated loading experience
- **Direct Navigation**: Clean navigation menu always visible
- **Hero Section**: Full-screen hero with waffle background image
- **Gallery**: 3-column grid layout with 361x361px images
- **Enhanced Footer**: Complete business information including contact, hours, and delivery details
- **WhatsApp Integration**: Direct order placement via WhatsApp
- **Responsive Design**: Works on all devices

## Installation

1. Extract the tar.gz file:
   ```bash
   tar -xzf waffle-it-bold.tar.gz
   cd waffle-it-website
   ```

2. Open index.html in your browser or serve with a local server:
   ```bash
   python3 -m http.server 8000
   ```

3. Visit http://localhost:8000
